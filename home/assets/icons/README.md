# App logos

White monochrome marks, drawn by the home screen as CSS masks. Brand marks identify their services; their owners keep their trademark rights, and no endorsement is implied. Simple Icons marks are CC0 (text in `SIMPLE-ICONS-LICENSE.txt`); exact sources and adaptations are in `SOURCES.json`. `apps`, `livetv`, `hdmi` and `homebrew` are original. There is no Simple Icons mark for Canal+, so it uses the TV's own icon.
